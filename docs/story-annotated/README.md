# Annotated scene files

These are the scene builders' own versions of each scene, with their explanatory comments, saved
when the 14 scenes were joined into one file to fit the 60 KB limit.

**The site does not load anything in this folder.** The running story is `js/story/scenes.js` and
`css/story/scenes.css`. Later fixes went into those two files only, so where this folder and the
running files differ, the running files are right. Use this folder to understand why a scene is
built the way it is.
